Sciev

science + evaluation — an open, typed decision layer for scientific evidence.

Unstructured state + typed questions → structured decisions with calibrated probabilities, in one forward pass — no text generation, no output parsing. Sciev attaches small specialist heads (choice / noul / score) to a frozen masked-diffusion backbone (LLaDA-8B), in the spirit of TypeSafe AI's System-One/Jev contract — but open, reproducible, and evaluated as science.

Install & evaluate

pip install sciev
gh release download v0.2.2 --repo alrobles/sciev --pattern 'fr_*.pt' --dir release
python -m sciev.eval --ckpt release/fr_choice.pt --decision-type choice \
    --r2-mode spanpool --r2-layers=-1,-9,-17,-25 --canonical-order \
    --decisions-eval my_decisions.jsonl --device cuda --out eval.json

Also exposes a /v1/systemone-compatible server (pip install sciev[serve]): drop-in typed decisions with the same frozen heads used in the evaluations.

Release heads are the frozen-backbone arm (fr_*). The DAPT arm (da_*) is experimental: under matched seeds it improves out-of-domain verification (+22.6pt SciFact) but degrades in-domain ordinal scoring.

Honest evaluation, built in

  • Dev-only calibration — temperatures and acceptance policies are fitted on dev splits and bound to the checkpoint hash before test evaluation.
  • Evidence controls — empty and shuffled-passage variants of every eval. They reveal real limits: choice keeps ~0.80 agreement without evidence (option-side leakage) while score collapses to chance.
  • Registered exclusions — inputs exceeding the token budget are excluded with reasons in manifests, never silently truncated.
  • Provenance — dataset manifests with SHA-256 fingerprints; 32 archived evaluation JSONs ship with each release.

Where it fits

Evidence-grounded QA, claim verification, rubric scoring, routing and tool selection — wherever you need a calibrated accept/escalate decision rather than generated text. Not a generator; it complements, not replaces, reasoning models.
